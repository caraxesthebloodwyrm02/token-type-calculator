Token Type Annotations — Signal Glossary
TRANSISTOR
Binary gate signal. Value "1" = armed & fired. Value "0" = fired unarmed. armedAt must be set before firesAtStep or anomaly is raised. Highest authority weight.
DECORATED_VAR
Environment variable injection at a designated triggerStep. Sets runtime context (e.g. HARNESS_EVENT_PROGRESS). Always fires regardless of gate state.
AMBIENT
Background passive signal. Emitted continuously across zone steps. Used for telemetry, heartbeat, and baseline drift measurement. No gate dependency.
ANOMALY
Signal fired in silence zone (steps 44–47) or when transistor fires unarmed. isAnomaly: true. Counted in anomalyCount. Triggers review before advancing layer.
GATE · ARMED
Transistor gate reached armedAtStep with state ON. armedAt timestamp is set. Gate will fire value "1" at firesAtStep. Clean path — no anomaly.
GATE · UNARMED
Gate reached firesAtStep with state still OFF. armedAt is null. Fires value "0". isAnomaly is set to true. Indicates missing Probe context or layer skip.
ZONES
Buildup (0–43): intensity 0.1→0.7, gate arming window. Silence (44–47): intensity 0.0, all signals are anomalies. Drop (48–67): intensity 1.0, transistor fire zone.
BARTER RATE
Exchange ratio between token types weighted by intensity × momentum × score. Transistor:Decorated = 1.0:0.72 baseline. Anomaly presence degrades all rates by drift factor.
